# 指标与边界

所有命令从 Skill 根目录执行。

- **基线**：创作者×平台的已知播放中位数，含零、排除缺失；同时报总条数及 n_views。K/M/B 为显示近似值，不能凭计算小数制造精度。
- **倍数**：单条播放 / 自身平台中位播放。分母为零或缺失时为 null；零播放在非零基线下为 0。
- **命中率**：已知倍数中达到 --hit（默认 3）的比例。与中位倍数、样本数一起报。topic/form 按创作者×平台分格，默认至少 20 条，少样本格缺席不等于零。
- **突破**：采样中第一条达到 --breakout（默认 100000）的内容；IG/TT/YT 分别计算，两侧各至少 5 条有效播放，报前后中位及条数。不是历史首次，不证明突破造成持续增长。
- **发布频率**：观测首末日之间条数 / 月数，月按 30.44 天。单日窗口频率为空；短窗口外推很不稳定。不是从注册日起号速度，更不是涨粉。没有历史粉丝观测就不算涨粉。
- **跨平台配对**：人工看内容后为相同内容设置相同 content_id（自行在 tagged CSV 增加列）。以 IG 为锚点，±2 天，按日期距离一对一；每条在一个平台对内最多一次。无 content_id 不配对。输出 pairs 明细和各平台配对数。日期相近不能验证内容相同，重复同一内容 ID 时须检查多次发布歧义。
- **网格窗口**：去除明确指定的前导置顶，再按日期由近到早排序，取最多 N 条（默认36、最少6）。先取时间窗口再核对播放，窗口内存在未知播放时拒绝分段，不能用更旧帖子补足。分段边界为 floor(i*N/3)，余数保留；报 segment_n、首末日期与 window_days。同日顺序依赖输入，重要分析须采精确时间。
- **播放/粉丝**：中位播放 / 当前粉丝；未知和零粉丝比值为空。这不是触达人数、粉丝转化或历史效率。
- **近/早**：最近段中位 / 最早段中位。内容年龄、未累积够的曝光、样本保留与时间窗不同都会影响它；不能单凭这个比值称为衰退。

## 标签

topic：使用 caption、标题、转写或画面文字，规则模板仅是示例，不同赛道自行调整。规则命中不等于语义正确，抽样核验并报告一致率。
form：P 真人出镜 / S 实景 / A AI画面 / T 文字或录屏 / R 他人素材。需要原片证据；AI与来源性质不明时留空，不根据脸或模板断言。
forms.json 优先使用完整 URL 键，shortcode 跨账号/平台重复时脚本拒绝歧义。--merge 用原始 URL 合并人工选题标签。

```bash
python3 scripts/label.py dataset.csv templates/topic-rules.example.json dataset-tagged.csv --form forms.json
python3 scripts/label.py dataset.csv templates/topic-rules.example.json dataset-tagged.csv --merge dataset-tagged-unmatched.csv
```

CSV 输出对可能执行公式的文本添加单引号，原始 CSV 保留用于逐字核对。公开观看行为不自动授予再发布素材或个人信息的许可。
