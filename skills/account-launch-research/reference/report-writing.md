# 把数据写成可决策的报告

报告要回答已约定的问题。可以采用封面 → 关键发现 → 逐项证据与建议 → 附录，数量由证据决定。不要照抄例子的数字、平台选择、内容配比或结论。

每节给出一句限定范围的发现、必要图表、行动建议及替代解释。样本量、关键缺口与不确定性靠近结论，不能只用灰色小字藏在附录。数据不足也是有效结果。

图型：
- lift：前后数值，log1p 轴，含零可绘制；这不是因果图。
- share：0–1 比例；超过1请改用 bars，不能截断成100%。
- quadrant：同量纲坐标比较，对角线仅在两轴同口径时有意义。
- paired：两个系列；相同值和零值均支持。默认普通数值；比值需显式写 unit: "×"，不能给播放数标倍数单位。
- bars：多系列数值，避免太多类别。
- scatter：非负数值散点，相关不代表因果。
- mix：非负构成且总和为1。

复制 templates/report.skeleton.json，把所有占位符和假数字替换成本轮证据。报告数字由脚本复算；渲染器不验证结论真假。空图表显示缺数据，不补假值。

```bash
python3 scripts/render_report.py report.json report.html --standalone
```

命令从 Skill 根目录执行。HTML 只允许基本文字格式和 HTTP(S) / 页内链接；脚本、事件属性、图片及自定义样式会被移除。渲染默认离线，无外部字体。打开页面实际检查后交付，同时提供数据与复算命令。
