
# Renee AI Toolkit

Renee 实际使用并持续迭代的 AI 指令模板与 Skill 工具包。按你要解决的问题选择资源，再根据自己的项目调整。

## 你想解决什么问题

| 你的问题 | 资源 | 类型与用法 |
| --- | --- | --- |
| 长任务换个会话，AI 就忘了进度？ | [Claude Code 长任务三件套](templates/claude-code-long-task/README.md) | 指令模板：复制使用，也可保存为自己的自定义命令 |
| 想做海外账号，不知道如何研究对标账号与起号方向？ | [海外账号与起号调研](skills/account-launch-research/README.md) | Skill 工具包：安装整个目录，结合获授权数据分析与生成报告 |

两类资源相互独立，可以只用其中一种。

## 怎么使用

- **指令模板**：打开三件套入口，选择开工、收尾或文件检查模板，复制其中的指令。下载仓库不会自动注册命令。
- **Skill 工具包**：按工具包 README 安装整个 `skills/account-launch-research/` 目录；方法、脚本、模板与示例需要一起保留，不能只复制 `SKILL.md`。

## 隐私与许可

请勿把密码、Token、Cookie、客户资料或私人交接提交到公开仓库。使用云端 AI 或第三方采集工具前，确认输入范围及对应服务的数据处理方式；调研仅处理获授权数据，结论需保留来源与局限。
